# Capability status

Development snapshot for **November 24, 2026** and Revit **2027.3**. Check the loaded feature flags and workflow contract for the active installation. See the [agent modeling guide](agent-modeling-guide.md) for installation, authorization, preview and execution.

**Native** means the stated scenario was checked in Revit. **Persisted scope** additionally means selected results survived a manual save/reopen. **Offline** means source/rule tests or compilation, without a successful native scenario. **Blocked** identifies an unmet prerequisite or failed result. These are separate from workflow availability. A successful commit alone does not prove the user's result.

Supply fresh `documentIdentity` and `expectedRevision` where the live contract requires them. Resolve all IDs from that document. Model coordinates are millimeters at the internal origin with absolute Z; paper coordinates and column XY inputs follow their explicit operation contracts. The input column lists the consequential choices, not every optional field.

No row certifies full model side effects, design compliance, automatic routing, another user's assets, or production readiness on the recipient's machine. Unknown native state remains unknown. Ordinary modeling does not automatically save or restart Revit.
