# 导线替换与开关控制编号迁移

统一入口为 `revit_workflow_run`，工作流 `electrical.wire`。复用现有原生 `delete_element`、`create_wire`、`set_parameter` 和事务/收据机制，不运行 `create-wires.csx`，不增加 Revit 二次确认，不自动保存。

## 领域输入

- `wires`：明确的现有 `firstElementId`、`secondElementId`、`viewId`、`wireTypeId`；可选 `id`、`firstConnectorId`、`secondConnectorId`、`bends`。
- `bends` 仅接受毫米 XY 点。原生创建导线时使用第二端连接器的 Z；不接受会被忽略的输入 Z。当前沿用 Chamfer，不提供其他布线形状的隐式选择。
- `wireDeletions`：逐项提供已有导线的 `elementId` 和 `viewId`。每个删除所属视图必须同时提供新导线，不能只删除、按固定数量删除或清空整个项目。
- `switchControls`：逐项提供现有开关的 `elementId` 和非空 `controlId`；只修改内置开关 ID，不接受任意参数名称。
- 保留 `tags`、`dimensions` 和可选嵌套文档身份/revision。

领域列表不接受原始 `operations`、代码、脚本/文件路径或未知字段。该工作流使用当前已存在的设备、类型和视图；需要同时新建灯具或视图时使用相应照明工作流。编号重复是否符合设计不由插件猜测。

以下 ID 只是接口示例，不代表任何项目中的真实元素。助手应先查询当前项目，再填入真实值，不要求用户手动填写 JSON。

```json
{
  "name": "electrical.wire",
  "planningMode": "explicit",
  "documentIdentity": "由当前 context 查询获得",
  "expectedRevision": 0,
  "input": {
    "wireDeletions": [{"elementId": 1001, "viewId": 2001}],
    "wires": [{
      "firstElementId": 3001, "secondElementId": 3002,
      "firstConnectorId": 1, "secondConnectorId": 1,
      "wireTypeId": 4001, "viewId": 2001,
      "bends": [{"xMm": 1500, "yMm": 2000}]
    }],
    "switchControls": [{"elementId": 5001, "controlId": "K7"}]
  }
}
```

## 预览和校验

1. 先校验领域输入及总操作上限，拒绝重复删除/控制目标、缺失替代导线、相同两端、空编号和未知字段。
2. 使用普通预览适配器固定当前文档 identity/revision。
3. 只读检查指定旧导线、视图、开关；每批最多 100 项，全部批次必须完整，缺失/重复/非请求项均停止。
4. 删除目标必须是所属视图一致的原生 `Wire`；视图必须是非模板 `ViewPlan`。控制目标必须是 `LightingDevices` 族实例，开关 ID 参数必须存在、唯一、可写、字符串类型且原值可验证。
5. 再读上下文，检查项目/revision/路径/保存状态未变化，才调用原生预览。返回 `domainReview`：指定旧导线及原类型、开关编号 before/after 和预览时 noChange。
6. 计划顺序为删除指定导线 → 创建明确新导线 → 设置指定控制编号 → 可选标记/标注。原生执行异常仍按现有整组事务机制回滚。
7. 预览后的上下文变化会取消已知计划一次；异常和超时不自动重试、不自动提交。

`ask` 返回导线范围、类型、接口、替换和控制编号的问题，不访问 Revit，不创建计划。`assisted` 必须披露非空假设，仍是候选预览，不自行设计回路容量或路线。

## 删除与工程边界

`selectedScopeVerified: true` 只证明直接指定的旧导线/开关范围通过检查，不证明最终删除集合。原生 `plan.warnings` 的依赖信息必须展示；当前依赖 ID 警告最多显示前 20 项。`exactDeletionCascadeVerified: false` 明确表示未认证精确删除级联或无副作用。

执行后必须检查收据的 `nativeChanges`、新导线原生 peers/类型/视图/折点、被删除元素和开关 ID；不能仅凭导线数量不变就算验收成功。原生生成导线并不证明设计合规。
