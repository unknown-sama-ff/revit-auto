# v0.3.22 泵房局部碰撞/净距核查实施计划

日期：2026-10-05。用户已批准对应设计文档；writing-plans 技能未安装，按仓库既有文档结构记录可执行计划。

1. 将设计状态标记为通过；补齐数值/候选数量/几何工作量安全边界。
2. 新增无 Revit 依赖的 CollisionCheckRules：输入严格验证、项目坐标包围盒关系、碰撞判定三态和体积阈值；核心测试先覆盖这些边界。
3. 新增 CollisionCheckService：UI 线程只读查询，实例变换递归、有效原生实体读取、有限包围盒候选、布尔相交、未知/截断诊断；不创建临时元素或事务。
4. MCP 暴露 revit_collision_check；bridge 加 collision-check 能力门控。默认不要求新聊天确认，因为此工具只查询。
5. 契约测试覆盖字段、非法数值、只读注解、分类证据透传、旧插件拒绝和身份/版本错误。完整回归与 Release 编译后，版本切换到0.3.22的独立输出目录。
6. 添加可重复的只读实机验收脚本，核对模型/保存状态不变并保留本机证据；旧插件只做门控验证，不声称已测新版几何。
7. 安装清单并核对目标程序集版本；不关闭Revit。提交/推送代码与文档，不上传模型、连接密钥或本地验收数据。
8. 用户重启后执行实机 clearanceMm=0 验收；维护净距只在用户提供值后检查，不自动套用标准。

关键范围说明：按已批准设计，targetElementIds 整组不作为外部候选。要检查水泵与非相邻回折管段，验收逐个目标查询，仅排除原生已核实的直接邻接端口元素，不把整条路线永久排除，避免组内漏检。任何结果都只针对声明的范围，不声明工程合规。
