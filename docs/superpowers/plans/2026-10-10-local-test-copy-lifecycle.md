# 本地测试副本生命周期实施计划

依据已批准的 `../specs/2026-10-10-local-test-copy-lifecycle-design.md`。仅实现与隔离验证，不注册新构建、不保存/退出/打开实机项目。writing-plans 技能在本机技能目录不存在，本文件采用项目既有模块、测试与构建流程。

1. 纯 C# 规则和持久存储：严格请求与固定目标登记、文件/进程指纹、阶段摘要链、只增单次标记、终止与租约规则；CoreTests 覆盖恶意字段、阶段重放、摘要变化、终态、路径别名和文件变化。
2. 原生服务与事件：预检、受控范围读取、单次保存/正常退出/固定打开；App 事件绑定，队列租约与退出立即结束 ExternalEvent；严格保护当前身份与原生状态，保存/打开结果未知时不重试。
3. MCP：生命周期严格 schema、能力门禁、只读/非只读声明，固定 scope 核验与错误传播；真实 stdio 合约和模拟桥接故障测试。
4. 外部监督器：prepare 固定目标/证据；execute 固定已审请求摘要、磁盘备份、短周期进程/持久事件监督、单次启动/continuation permit、新会话两轮验收；入口 PowerShell，测试以模拟进程和临时 fixture 为主。
5. 集成与独立复审：协调字段和文件契约；运行 CoreTests/MCP 全量回归、监督器测试、实际 27.3 API 隔离编译/CheckOnly，修复所有阻断；生成具体可审构建与注册申请后再请求批准。

实施检查不得调用 `revit.plan.confirm`、`Document.Save`、退出或打开实机文档；不得修改现行注册、活动 DLL、2025 资产、凭据或 ACL。已有 AL1、复制类型及 unresolved 验收边界保持原记录。
