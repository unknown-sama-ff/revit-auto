# v0.3.18 泵管连接兼容性

本版本修复上一份泵管连接计划的问题：

- 新建管道尚未加入系统时，不能只读取即时 `Connector.PipeSystemType` 判断分类。
- 连接执行现在同时核对计划中的原生系统类型、元素分配系统类型和连接器即时分类。
- 有冲突或未知证据时拒绝连接并返回双方元素、端口和分类证据。
- 同一端口或新管道同一端点被重复使用时，在预览阶段拒绝。
- 旧的失败计划不可重试；回滚后必须使用当前 revision 重新预览。

泵房路线的安全拓扑是：

```text
泵连接器
  → 200 mm route1（垂直）
  → elbow
  → 200 mm route2（水平）
  → elbow
  → 200 mm route3（垂直）
  → elbow
  → 200 mm route4（水平至现有管道端点）
  → transition 200 mm → 80 mm
  → 现有管道连接器
```

每个弯头占用不同的新管道端点，变径只使用 route4 的另一端点；不得重复使用已经被弯头占用的端点。

执行前需要重新读取：

- 水泵连接器方向、直径、系统分类；
- 现有管道连接器方向、直径、系统分类；
- 当前文档 identity/revision；
- 当前管道和管件基线。

必须先显示预览并获得聊天确认。Revit 不会二次弹窗，项目不自动保存。
