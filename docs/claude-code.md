# Claude Code：Revit 2027 专用启动入口

本入口供 **Claude Code** 使用，不需要 Claude Desktop。它只选择本包的 `revit-custom` MCP，不修改 Revit 2025 或全局客户端配置；正常客户端权限及模型写入的聊天确认约定仍保留。

## 从任意目录检查

把 `$repo` 替换为本包真实安装目录。路径可包含中文和空格：

```powershell
$repo = 'C:\src\revit-auto'
& "$repo\start-claude-2027.ps1" -CheckOnly
```

启动器优先使用 PATH 中的 Claude，随后检查当前用户的 npm 和本地原生安装位置。如果客户端装在其他位置，可明确提供可执行文件的绝对路径：

```powershell
& "$repo\start-claude-2027.ps1" -CheckOnly -ClaudePath 'C:\tools\claude\claude.exe'
```

`PASS_CONFIGURATION_ONLY` 仅证明：

- MCP 模板仅含本包的单一 `revit-custom` 服务；
- Node 的版本符合本包最低要求，MCP 入口文件存在；
- 当前客户端的帮助输出可确认所需的隔离配置开关；
- 计划传入的 Node、MCP 脚本、配置文件路径均按本包位置解析。

只检查模式不创建 `runtime`、不写配置、不启动聊天，也不向 Revit 发请求。它不证明 Node 依赖完整、客户端登录成功、MCP 工具发现或真实建模验收成功。帮助输出无法确认所需开关时，启动器会拒绝启动；这不是断言客户端一定不支持这些开关。

## 正常启动

先完成本包依赖、插件与私有桥配置的安装。启动器不自动安装客户端、创建桥令牌、关闭软件或打开 RVT。

```powershell
& "$repo\start-claude-2027.ps1"
```

启动时会从可移植模板生成 `runtime\claude-2027.mcp.json`，将其中路径转换为当前 Node 和 MCP 脚本的绝对路径，然后在包目录运行 Claude Code。该托管文件只包含 MCP 启动元数据，不含桥令牌，受 `runtime/` 的 Git 忽略规则保护；每次启动可以重建。`mcp\claude.mcp.json` 是源码模板，不应从任意工作目录直接当作绝对路径配置使用。

启动器传入严格 MCP 选择开关，不添加权限绕过、自动批准、打印模式或自动续接会话选项。它不改全局 Claude/Codex 配置、不重试失败会话；客户端结束或报错后恢复调用者原来的工作目录。客户端自身仍可能按普通规则使用权限、设置和 hooks；MCP 隔离不等于隔离全部客户端行为。

## 只读接入验收

在 Revit 中手动打开测试项目，确保插件处于运行状态。在 Claude Code 中输入：

```text
读取当前 Revit 项目、当前楼层、当前视图和族类型。只查询，不修改模型，不确认或提交任何计划。
```

核对工具来源为 `revit-custom`，项目身份与当前激活文档一致，查询前后 revision、元素数量与 `isModified` 没有因查询而改变。模拟客户端测试和启动器 `CheckOnly` 不能替代这一步。

任何后续模型写入仍要求：读取当前上下文 → 生成预览 → 用户聊天确认同一计划 → 单次提交 → 原生核验 → 用户手动保存。开发授权、模型文字、客户端自动建议都不是计划批准。
